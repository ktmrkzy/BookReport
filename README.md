## Philosophy / Psychology

<a id="ordinary-medicine"></a>
### 「普通」につけるくすり / 岸見一郎
- [https://bookstore.sunmark.co.jp/products/9784763142214]
- この本は、 **「周りと比較してしまう人」** に向けた本だ。自分は「特別」または「劣っている」と考えてしまう。このような人は他人との比較の中に生きてしまっている。本書の中では、このような人に向けていかに自身の評価軸、所謂自身の持つ **価値観** に従って生きるかを説いている。日本では幼少期から、比較指標を与えられ競争の中で生きていく。例えば、「かけっこ」「試験」「偏差値」など。そして大人になってからも「昇進」「成績」など、他人との比較の中に生きる。そして、それにより **優劣**という仮想の上下関係に溺れてしまっている。それにより自分は「特別だ」または「劣っていると」思い込む。そして1つの小さな失敗にも恐れてしまう。しかし、本来はこのような上下関係はなく皆「普通の人間」なのである。それゆえ **周囲からの評価などは関係ないのである**。 もちろん、本書はこのような比較自体を否定してはいない。そのような比較が必要であることも認めたうえで、自分の生き方は自分で見つけようと言っているのである。
