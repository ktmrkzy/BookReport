## Philosophy / Psychology

<a id="ordinary-medicine"></a>
### 「普通」につけるくすり / 岸見一郎
- <https://bookstore.sunmark.co.jp/products/9784763142214>
    <details>
    <summary>レビュー</summary>
    この本は、<b>「周りと比較してしまう人」</b>に向けた本だ。自分は「特別」または「劣っている」と考えてしまう。このような人は他人との比較の中に生きてしまっている。本書の中では、このような人に向けていかに自身の評価軸、所謂自身の持つ<b>価値観</b>に従って生きるかを説いている。日本では幼少期から、比較指標を与えられ競争の中で生きていく。例えば、「かけっこ」「試験」「偏差値」など。そして大人になってからも「昇進」「成績」など、他人との比較の中に生きる。そして、それにより<b>優劣</b>という仮想の上下関係に溺れてしまっている。それにより自分は「特別だ」または「劣っていると」思い込む。そして1つの小さな失敗にも恐れてしまう。しかし、本来はこのような上下関係はなく皆「普通の人間」なのである。それゆえ<b>周囲からの評価などは関係ないのである</b>。もちろん、本書はこのような比較自体を否定してはいない。そのような比較が必要であることも認めたうえで、自分の生き方は自分で見つけようと言っているのである。
</details>

<a id="cafe-on-the-edge"></a>
### 世界の果てのカフェ / ジョン・ストレルキー
- <https://www.diamond.co.jp/book/9784478122549.html>
    <details>
    <summary>レビュー</summary>
    - この本は<b>「漫然と過ごす日々に対する違和感」</b>を覚えた人が、そこから抜け出す、<b>「自分のやりたいこと、なんのために私は生きているのか」</b>を問い直し、自分の人生を取り戻したい人に向けた本だ。おそらく多くの人がそうだと思っているが、幼いころは白紙のキャンパスに自由な絵を描くように、自身の夢や欲望というものに忠実に生きようとしていたのではないだろうか。しかし人は成長していく中で、その場で適切とされる絵のアイデアや表現技法、所謂、常識というものを獲得していく。そうして、自身の信ずる生き方や自分の存在価値を問うことを無意識のうちにやめていくのだろう。この書籍の中では、その薄れつつある<b>「私らしい生き方」</b>というものを段階的に、（主人公とともに）模索していくような作品だ。ただし、<b>「このように考えてください」</b>と正解を与えるようなものではなく、"問" だけをあなたに与える。それは難しい問いではなく、<b>「あなたはなぜここにいるのか？」</b>というような、誰もが文言として理解はできるが、その回答には窮するようなものだ。そして、このような問いに答えるプロセスの中で、あなたは自分の存在価値を再発見していくのだ。
</details>

### デンマーク人の休む哲学 / 針貝有佳
- <https://www.daiwashobo.co.jp/book/b10149685.html>
    <details>
    <summary>レビュー</summary>
    これは幸福度ランキング上位国である、デンマーク人のライフスタイルの中にいかにして<b>休む習慣</b>が根付いているかを紹介している本だ。デンマーク人の中には<b>「ヒュッゲ」</b>と呼ばれる<b>休みの哲学</b>が根付いているようだ。これは、「安らぎを感じる心地よいひととき」を意味する言葉だそうだ。デンマーク人にとって「ヒュッゲ」するからこそ仕事の効率も高まるという考えなのだ。日本では「休みが取れない」「仕事が終わらない」と嘆く社会人が多いのではないだろうか。そして休みを蔑ろにしてしまい、仕事に対するモチベーションも高まらないまま、100%の力を出し切れないまま仕事をただこなしていく。さらには、<b>「休みがあっても何をしたらいいのだろう」</b>と休み方を忘れてしまった人もいるかもしれない。本書の中にはデンマーク人が休みに何をするか具体的に紹介されていたりもするので、具体的な休み方を知りたい人は一読してもらいたい。キーワードは<b>「ヒュッゲ」</b>である。どのようなときに人は安らぎを感じるのだろうか、人それぞれ違いはあると思うが、本書の中では「愛する人や信頼できる人、気心知れた人との何気ないひと時」というところに安らぎを見出しているように思う。つまり、スマホに向き合うでもなく、忙しなく色々なところに赴くでもなく、ゆったりとした時間の中で相手と時間を共有する感覚なのだと思う。そのような時間が生活の中でどれだけ重要で、我々に恩恵を与えるか本書の中で紹介されている。
</details>
