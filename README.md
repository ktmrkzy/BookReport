## Philosophy / Psychology

<a id="ordinary-medicine"></a>
### 「普通」につけるくすり / 岸見一郎
- [https://bookstore.sunmark.co.jp/products/9784763142214]
<details>
<summary>レビュー</summary>
この本は、 **「周りと比較してしまう人」** に向けた本だ。自分は「特別」または「劣っている」と考えてしまう。このような人は他人との比較の中に生きてしまっている。本書の中では、このような人に向けていかに自身の評価軸、所謂自身の持つ **価値観** に従って生きるかを説いている。日本では幼少期から、比較指標を与えられ競争の中で生きていく。例えば、「かけっこ」「試験」「偏差値」など。そして大人になってからも「昇進」「成績」など、他人との比較の中に生きる。そして、それにより **優劣**という仮想の上下関係に溺れてしまっている。それにより自分は「特別だ」または「劣っていると」思い込む。そして1つの小さな失敗にも恐れてしまう。しかし、本来はこのような上下関係はなく皆「普通の人間」なのである。それゆえ **周囲からの評価などは関係ないのである**。 もちろん、本書はこのような比較自体を否定してはいない。そのような比較が必要であることも認めたうえで、自分の生き方は自分で見つけようと言っているのである。
</details>

<a id="cafe-on-the-edge"></a>
### 世界の果てのカフェ / ジョン・ストレルキー
- [https://www.diamond.co.jp/book/9784478122549.html]
<details>
<summary>レビュー</summary>
- この本は **「漫然と過ごす日々に対する違和感」** を覚えた人が、そこから抜け出す、 **「自分のやりたいこと、なんのために私は生きているのか」** を問い直し、自分の人生を取り戻したい人に向けた本だ。おそらく多くの人がそうだと思っているが、幼いころは白紙のキャンパスに自由な絵を描くように、自身の夢や欲望というものに忠実に生きようとしていたのではないだろうか。しかし人は成長していく中で、その場で適切とされる絵のアイデアや表現技法、所謂、常識というものを獲得していく。そうして、自身の信ずる生き方や自分の存在価値を問うことを無意識のうちにやめていくのだろう。この書籍の中では、その薄れつつある **「私らしい生き方」** というものを段階的に、（主人公とともに）模索していくような作品だ。ただし、 **「このように考えてください」** と正解を与えるようなものではなく、"問" だけをあなたに与える。それは難しい問いではなく、**「あなたはなぜここにいるのか？」** というような、誰もが文言として理解はできるが、その回答には窮するようなものだ。そして、このような問いに答えるプロセスの中で、あなたは自分の存在価値を再発見していくのだ。
</details>
